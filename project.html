Projects · five of them

Five things I want to build

None of these exist yet. Each one is written down with what it needs and where it will hurt, so that the next evening I sit down there is nothing to decide first — only to start.

  1. 01

    A clock that shows the tide

    ★☆☆

    One round face, one hand, and the only thing it tells you is how much water is left.

    High water, low water, and the slow six hours between them. The face is a circle drawn in SVG with the twelve hours of a tide wrapped round it once, so a single turn of the hand is a single tide. Read the height of the hand and you know whether the rocks off the point are walkable this evening.

    • SVG
    • Date
    • tide tables

    Where it hurts: a tide is not twelve hours. A lunar day is 24 hours 50 minutes, so a simple clock drifts almost an hour a day and is useless within a week unless the drift is built in from the start.

  2. 02

    A light with a character

    ★★☆

    Type Fl(3) W 15s and watch the beam do exactly that, for as long as you leave it running.

    Every lighthouse is identified by rhythm: three flashes, a pause, the same again fifteen seconds later. This is a small page where you write the pattern and the light obeys — a white flash for the bright part, darkness for the gap, no clock graphics at all. The interesting part is not the drawing, it is keeping perfect time while the browser is busy.

    • setTimeout
    • requestAnimationFrame
    • CSS animation

    Where it hurts: a chain of setTimeout calls slowly loses time, and a drifting lighthouse is a lie. The rhythm has to be computed from a single start time instead, one step at a time.

  3. 03

    A keeper's log

    ★☆☆

    One line a night: weather, wind, and anything odd on the water.

    A page that opens on tonight's empty line, saves what you write and then draws the whole year as a ledger — dates down the left, one sentence each. On paper it is the least dramatic document in the world, which is exactly what makes it worth keeping. Export as plain text, so the record still opens in thirty years.

    • localStorage
    • forms
    • tables

    Where it hurts: dates. A log written at 01:00 belongs to the night before, not to the calendar day, and getting that wrong quietly ruins the whole ledger.

  4. 04

    A Morse lamp

    ★★☆

    Type a message, and a lamp on the screen blinks it out, one letter at a time.

    Before radio, ships talked with a shutter and a lamp. This is the same idea at one pixel's risk: a square that goes bright for a dot, stays bright for a dash, and pauses for exactly as long as the code says. Show the decoded line underneath as it goes, so you can read your own message coming back at you.

    • timing
    • arrays
    • keyboard input

    Where it hurts: the whole alphabet has to be typed out by hand, and a single wrong gap turns E into I and ship into nonsense.

  5. 05

    One coast, drawn from memory

    ★★★

    A chart of a coastline I know, with the lights marked in the right places.

    Not a real map: a line drawn by hand, the sea filled in dark, the towers marked as small amber dots, each one opening a note about a night I remember. Laid out in SVG, hoverable, printable in black and white, which is how charts were meant to be read anyway.

    • SVG
    • hover states
    • print styles

    Where it hurts: scale. Everything has to shrink together on a phone, and a fine hand-drawn line becomes a grey smear the moment it is scaled down.

The next one I will actually build is 02 — it is the one I would use, every night, for no practical reason at all.
